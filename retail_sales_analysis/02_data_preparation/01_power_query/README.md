# Data Preparation with Power Query

## Overview

Power Query was used to inspect, clean, and transform the original Excel datasets before importing them into PostgreSQL.

## Key Transformations

- Reviewed the source tables and their column structures.
- Corrected data types, including dates, numeric values, and text fields.
- Prepared numeric columns for consistent import into PostgreSQL.
- Checked key columns and data consistency.
- Exported the prepared datasets to CSV files for database import.

## Output

The cleaned CSV files are stored in `../02_cleaned_data/` and were used to populate the PostgreSQL database.
